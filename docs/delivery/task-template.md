# Task Template
## Title
`[Module] Verb outcome`
## Goal
What user/system outcome is required?
## Scope
In scope / explicitly out of scope.
## Sources
Relevant module, business rules, API/design references.
## Actor & permission
Platform or Clinic actor; required permission(s).
## Data changes
Entities, migration, constraints/indexes.
## API changes
Routes/contracts/errors.
## UI changes
Routes/screens/states/permission behavior.
## Business rules
Numbered rules that must hold.
## Acceptance criteria
Use Given/When/Then and include security/negative cases.
## Tests
Unit / integration / E2E / frontend.
## Risks & open decisions
Anything the agent must not guess.
## Done
Verify `docs/engineering/definition-of-done.md`.
