# Clinical Orders / Prescriptions
A configurable clinical document tied to clinic/patient/visit/doctor. Sections may be Structured, Text, Image or File and can represent medications, investigations, radiology, procedures, instructions and follow-up. Autocomplete may learn names for productivity but must never make medical recommendations.
## Cross-cutting rules
Apply actor/tenant isolation, authorization, validation, audit where relevant, standard errors/responses, UTC persistence and the global Definition of Done.
