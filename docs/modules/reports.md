# Reports
UX is Select Report → Apply report-specific filters → Generate Preview → Export PDF/Excel. V1 reports: Patients, Visits, Queue, Doctor Activity, Pending Documentation, Follow-Ups, Measurements and Audit. Enforce permissions and tenant filtering on preview and export.
## Cross-cutting rules
Apply actor/tenant isolation, authorization, validation, audit where relevant, standard errors/responses, UTC persistence and the global Definition of Done.
