# Product Vision
AURAN Clinic is a configurable clinic operating system that lets AURAN run many clinics from one product while keeping every clinic's data and operational configuration isolated.

V1 focuses on two outcomes: AURAN can securely onboard/control clinics through a Platform layer; clinic teams can run patient registration, live flow, visits, documentation, clinical orders, follow-ups and reporting without customer-specific code.

## Principles
- One product, one codebase, one schema, many clinics.
- Configuration over forks.
- Search before creating patient records.
- Operational flow and clinical documentation are related but independent.
- Permissions control actions and navigation.
- Auditability and tenant isolation are default requirements, not optional enhancements.
